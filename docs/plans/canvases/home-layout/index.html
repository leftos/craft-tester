Home page layout: one page or one step per screen?

Both lanes use the same pieces: VATSIM sign-in, a Continue banner for an unfinished test, airport, mode, practice or test, answer method, filters behind "More options", a copyable link for the session being set up, recent tests, and the tour link. The difference is whether they all sit on one screen or arrive one step at a time.

A. One page

Everything on one screen, with the last choices already selected. A returning student presses Start once. The link under Start changes as choices change, so every combination can be copied.
